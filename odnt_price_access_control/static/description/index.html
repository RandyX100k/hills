Product Price Lock Pro | Odonity

Restrict Product Price Editing with Role-Based Access Control

Control who can modify Sales Price and Cost Price in Odoo Products. Only users assigned to the Price Manager role can edit prices, while all other users see price fields as read-only — enforced at both UI and server level.

Key Features

  • Dedicated Price Manager Role to control price editing permissions
  • Sales & Cost Price Read-Only for unauthorized users
  • Dual-Layer Security with UI and ORM-level enforcement
  • Works Across All Views (Product form, variant, and list view)
  • Blocks API & Script Changes for complete protection
  • Clear Error Messages on unauthorized price updates

Perfect For

  • Retail & Wholesale Businesses managing product pricing
  • Manufacturing Companies controlling cost structure
  • B2B Distribution requiring price discipline
  • Sales Teams with restricted pricing access

Installation & Usage

  • Install like a standard Odoo app
  • Go to Settings → Users → Assign "Price Manager" role
  • Open any Product and try editing price fields
  • Only authorized users can modify prices
  • Unauthorized attempts will be blocked with an error
